## Design priority

The first version should prioritize the tracker/counter over the visual theme.

Because the FREE-WILi screen is small, the interface should stay simple, readable, and low-clutter. The player should always be able to see the five car counts and the total count clearly.

The Angry Birds-inspired direction should be treated as a later visual skin, not the first build. The final game can feel like launching cars into obstacles, but the MVP should remain a clear car-color tracker.

## Small-screen rules

- Show only one main screen at first.
- Keep all five color counts visible.
- Keep text large enough to read quickly.
- Avoid busy backgrounds.
- Avoid large icons until the counter works.
- Use short feedback text like “RED +1” or “NICE HIT.”
- Use simple stars only after the total counter works.
- Use tiny car/crash icons later only if they remain readable.

## Build order

1. Build the tracker logic.
2. Test keyboard input with the real FREE-WILi button order.
3. Add session saving.
4. Create a simple screen layout.
5. Move the logic to FREE-WILi.
6. Add small feedback effects.
7. Add the car-crash game theme.
8. Add tiny icons or pixel art last.
